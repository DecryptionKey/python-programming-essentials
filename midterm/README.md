# Midterm

Four problems from the midterm exam. Each file runs its own examples.

| File | Problem |
|------|---------|
| `problem_R1_6_sum_odd_squares.py` | R-1.6: sum of squares of odd positive integers below `n` |
| `problem_P1_29_cat_dog_strings.py` | P-1.29: all arrangements of c, a, t, d, o, g |
| `problem_R2_4_flower.py` | R-2.4: `Flower` class with name, petal count, and price, plus getters and setters |
| `problem_R2_5_credit_card.py` | R-2.5: `CreditCard.charge` and `make_payment` reject non-numeric arguments (including `bool`) |

```bash
python3 problem_R2_5_credit_card.py
```

`pyproject.toml` and `uv.lock` are from the project setup; there are no dependencies, so plain `python3` works.
