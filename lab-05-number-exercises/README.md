# Lab 5: Number Exercises

All five programs prompt for a number.

| File | Exercise |
|------|----------|
| `problem_14.py` | Reverse an integer (keeps the sign) |
| `problem_15.py` | Largest and smallest digit in a number |
| `problem_16.py` | Check whether a number is a palindrome |
| `problem_17.py` | Factorial of a non-negative integer |
| `problem_18.py` | Collatz sequence until it reaches 1 |

```bash
python3 problem_16.py
```
